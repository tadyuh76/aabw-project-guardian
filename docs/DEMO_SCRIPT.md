# Three-minute demo

1. Open Today and point to the Marketplace, Guardian-owned, Customer Service,
   and Social coverage strip.
2. Read the top Act now card: what changed, likely customer-reported driver,
   market context, next move, and primary owner.
3. Open Evidence to show current/baseline definitions, stratum counts, the
   separate public benchmark, redacted records, confidence, and data health.
4. Switch roles to show that viewer guidance changes while facts, owner, and
   core actions remain invariant.
5. Run `./scripts/demo-increment`; it submits one stock-cancellation fixture and
   polls the returned run until the separate signal crosses the action threshold.

Close with: “It finds what changed, explains the likely customer-reported
driver, compares the market, and tells the right team what to do next.”
